# 備貨與活動管理

入口：管理 → 抽獎與獎品管理 →「備貨與活動管理」。沿用抽獎管理權限；一般老師繼續使用學生領獎頁。

## 備貨／姓名貼

1. 按「備貨／姓名貼」，可篩選館別、獎品與狀態；每頁 50 筆。
2. 勾選項目後按「列印勾選姓名貼」。每筆一張，包含學生姓名、完整 Email、獎品名稱與尺寸、件數、館別。姓名貼不是領取憑證，實際交付仍須在系統登記。
3. 只有實物確實送到指定館別後，才勾選並按「核對勾選項目到館」，每批最多 10 筆。
4. 核對整批名單後，按「確認到館並通知學生」。系統逐筆處理，沿用 LINE 優先及既有備援規則。
5. 若某筆通知或連線結果不明，後面的項目停止。查看本批結果，再更新清單與寄信紀錄核對；不要整批重送。

## 學生活動紀錄

輸入完整 OB Email，可同頁查看可用星星、日期異動、購卡核對、照片與推薦申請、抽獎、獎品領取與通知紀錄。每類最多 50 筆／頁，可往後翻頁。四館課次以已完成同步為準。

若尚無經 OB 驗證的 LINE 身分，不推測學生是誰，先顯示現有領獎資料；活動端暫時無法讀取時會明確標示。查詢不抓新 OB 資料、不加星、不寄訊息。

## 庫存提醒

「可用」採獎項表剩餘數，不重複扣掉已中獎待領的數量；球依原本領獎日誌計算。待領與已交付另列，供備貨核對。

每項預設提醒門檻為 5 件。可改門檻，並勾選「低庫存時通知 Tako 的系統收件匣」後儲存。預設只在頁面顯示，系統通知需勾選啟用；沿用每五分鐘備貨同步，在活動同步期間檢查。同一段低庫存期間不重複提醒，補貨高於門檻後再次跌破才提醒。未新增學生通知。

## 下次活動草稿

填入下一次活動名稱，預覽後保存。複製目前啟用的獎項、機率、圖片、領取方式與本次集星規則；已停用的束口袋等獎項不會帶回。

草稿保持停用，庫存／已配置數歸零，活動日期、領取期限、折扣碼、學生顯示說明與資料來源須重新確認。學生、身分驗證、中獎及領取紀錄不搬入。可下載完整 JSON 草稿，作為下一次設定的來源；保存草稿不會建立新活動或啟用排程。

## 本次驗證與資料影響

已測權限、同編號重複提交、來源與版本變動、批次結果不明停止、庫存提醒去重、完整 Email 隔離、停用草稿重設，以及手機／桌面操作。通知使用模擬資料驗證。

發布程式本身不執行通知，不修改學生或獎項資料。只有管理者儲存門檻或草稿時，才會追加 ActivityToolJournal 管理紀錄；既有試算表欄位及索引維持。
