# VVIP 課表顯示請假與代課狀態

## 目的

VVIP 選課頁仍以 `CourseList` 的實際 OB 課程作為唯一可勾選課程，但同時合併 `請假代課紀錄`，讓會員看得出原老師是否請假，以及是否已有代課老師。

## 顯示規則

- 沒有有效請假紀錄：維持目前課程名稱、老師與「可登記」。
- 已請假但尚未領取：課程仍可登記，顯示「原老師請假｜代課老師未定」。
- 已有人領取：主內容顯示 `CourseList` 的實際課程與老師，另顯示「原老師請假：老師名稱」。
- 已取消的請假不顯示請假或代課標記。
- 同一 OB Calendar ID 有多筆紀錄時，忽略已取消資料，採用最新一筆有效紀錄。
- 改課或特別課可透過原始 `OB Calendar ID` 與 `替代 OB Calendar ID` 配對；同一實際課程只產生一個可勾選項目。

## 資料流程

後端 `getVvipCourseRows_` 一次讀取下個月 `CourseList` 與 `請假代課紀錄`，先建立 Calendar ID 對照表，再把顯示用欄位合併進既有課程物件。前端只負責呈現後端提供的請假與代課標記，不另外發第二次請求。

## 安全與相容性

- 不修改 `CourseList`、`請假代課紀錄` 或 VVIP 人工資料。
- VVIP 送出仍使用課程原本的 OB Calendar ID，不改變四堂上限與去重規則。
- 未合併到請假資料時維持現有畫面，避免影響一般課程。

## 驗證

- 後端測試涵蓋一般課、待代課、已領取、已取消、同 ID 新舊紀錄與替代 Calendar ID。
- 前端測試確認請假／代課文字可見，且只有一個 checkbox。
- 完整回歸後再決定是否正式部署。
