# 管理頁老師邀請輪次設計

## 目標

將「選擇本輪邀請老師」整理成固定輪次，讓管理員可以一次勾選一排老師，不再因邀請狀態改變而重新排列名單。

## 名單範圍

- 使用現行授課老師名單，共 32 位，順序依管理員提供的表格。
- 每 5 位為一輪，最後一輪 2 位。
- 姝姝包含在正式輪次中。
- 冠蓉為管理員，不顯示。
- 狗狗 陳、Lydia 慕恩、尚昀 陳、Angela 為暫時未授課的備用老師，不顯示。
- 若後端未來出現不在固定名單、且不屬於排除名單的新老師，放入「其他老師」區，避免新帳號被隱藏。

## 互動

- 每輪獨立顯示「第 N 輪」與「勾選本排」按鈕。
- 「勾選本排」只勾選該輪目前可邀請的老師；全選後按鈕可切換為「取消本排」。
- 已在「邀請中」的老師仍保留在原輪次，但顯示「邀請中」並停用勾選。
- 原有「開放給勾選老師」與「複製 LINE 邀請文字」流程不變。
- 手機版保留相同輪次分組；輪內姓名可換行排列，不強迫五欄造成破版。

## 資料安全

- 僅調整前端名單呈現與勾選互動。
- 不修改 GAS、Google Sheets、邀請資料或既有 API 契約。

## 驗證

- 測試固定名單順序、排除名單、五人分輪及最後一輪兩人。
- 測試邀請中的老師仍顯示且不可勾選。
- 測試整排勾選不會勾到邀請中的老師。
- 檢查桌面與手機版畫面。
