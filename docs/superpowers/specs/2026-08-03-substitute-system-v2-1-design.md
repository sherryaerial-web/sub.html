# 代課系統 v2.1 設計規格

日期：2026-08-03
專案：Sherry Aerial Studio 教室內部管理網站／代課模組
前端：`sherryaerial-web/sub.html`
後端：Google Apps Script + Google Sheets + Omcean Booking API

## 範圍與目標

本階段完成登入、請假、隱藏邀請、領取代課、取消／退出、Omcean Booking（以下簡稱 OB）人工處理與 API 核對。薪資模組只共用登入基礎，不在本階段實作。

系統要取代分散在 LINE、Excel 與人工逐筆比對的流程，同時保留管理者手動決定邀請順序與 OB 寫回時機的控制權。

## 角色與權限

### 老師

- 以可搜尋姓名與身分證末碼登入，不使用 Email。
- 登入後只可讀取自己的課程、請假、代課與異動紀錄。
- 只有目前被管理者邀請時，才可查看待領取代課。
- 不得查看邀請梯次、序位、其他受邀老師或他人的私人資料。

### 管理者

- 可手動同步 OB 課表。
- 可選擇一位或多位老師開放代課領取資格。
- 可手動關閉個別老師的領取資格或暫停全部領取。
- 可處理取消請假、退出代課、OB 修改與核對異常。
- 可查看完整操作紀錄，但密碼與 API token 不得由前端讀取。

## 統一登入

- 登入介面採「可搜尋姓名＋身分證末碼」，維持既有薪資登入習慣。
- 瀏覽器只可記住上次選擇的老師姓名，不保存末碼。
- 後端驗證成功後建立有期限的 session；所有個人與管理 API 都要驗證 session。
- 身分證末碼以雜湊值保存，不以明碼回傳或提供前端下載。
- 連續登入失敗要有短暫限制，避免大量猜測。
- 未來薪資模組共用此登入，但薪資資料與權限另行設計。

## 手動同步 OB 課表

API 端點為 `GET https://api.omceanbooking.com/v1/calendar`，Bearer token 只存在 Apps Script Script Properties 的 `OMCEAN_API_TOKEN`。

- 只有管理者按下「同步 OB 課表」時才執行，不建立自動排程。
- 同步區間為執行當日至下個月底，例如 2026-08-03 至 2026-09-30。
- 每頁最多 100 筆，以 `start` 分頁取得完整資料。
- 排除取消課程，並保存穩定的 OB calendar ID、class ID、老師 ID 與最後同步時間。
- 完整抓取並驗證成功後才替換 `CourseList` 快照；任何 API 或資料格式錯誤都保留舊資料。
- API 同步只更新目前 OB 課表，不得覆蓋既有請假與代課歷史。

## 請假流程

1. 老師登入後只看到自己的課程。
2. 先選一個或多個日期，再顯示所選日期的課程。
3. 日期區提供「全選目前可見日期」與「清除全部」。
4. 老師勾選課程後，確認頁顯示總堂數及完整清單。
5. 前端以 POST 分批送出，後端回傳實際成功與失敗筆數；只有全部成功才顯示完成。
6. 每筆請假保存送出當下的原老師、日期、時間、課程與 OB calendar ID，後續同步不得改寫。
7. 同一老師、OB calendar ID 不得重複請假；舊資料缺少 ID 時才使用日期、時間與課程作備援判斷。

「我的請假紀錄」要顯示請假內容、目前狀態、代課老師、預計改課內容、OB 核對結果與異動紀錄。

## 隱藏邀請與代課領取

1. 管理者勾選一位或多位老師，按「開放代課」。
2. 系統產生可貼到 LINE 的通知文字，通知仍由管理者手動傳送。
3. 受邀老師登入後可查看當下全部尚未領取的代課，依日期分組。
4. 老師自己請假的課不顯示，後端也禁止領取。
5. 邀請沒有自動期限，管理者手動決定何時關閉或邀請下一批。
6. 後台記錄邀請時間、首次查看時間、領取結果與關閉時間。
7. 「暫停全部領取」可立即阻擋所有領取，但不刪除邀請與歷史。

多人同時領取同一堂課時，後端必須使用 `LockService` 並在鎖內重查狀態。只有第一位可成功；其餘回傳「此課程剛被其他老師領取」，前端隨即移除該課程。

## 領取時的課程、難度與備註

每堂領取資料需分開記錄：

- 實際要上的課程／道具
- 難度或等級
- 備註
- 處理類型：沿用原課程、改用既有 OB 課程、需要新增課程

若代課老師具備原道具的授課資格，備註選填，但仍可調整難度或補充特殊事項。若不具備原道具資格，必須選擇或填寫實際課程，並填寫備註後才能送出。

若 OB 尚無所需課程，可選「需要新增課程」，填寫建議課名、道具、難度及備註；管理者完成 OB 新增後再建立新舊課程對應。

## 取消請假與退出代課

### 取消請假

- 尚未有人領取且尚未開始處理 OB：原老師可自行取消，保留取消時間與紀錄。
- 已被領取或已開始處理 OB：原老師只能提交取消申請與原因，由管理者確認。

### 退出代課

- 代課老師領取後不得直接放回。
- 代課老師提交退出申請與原因，由管理者確認。
- 管理者確認後，清除目前領取狀態並重新開放該堂課給仍具資格的受邀老師。
- 所有異動採狀態轉換，不刪除原始資料。

## 管理待辦中心

管理端分成六個工作區：

- 待邀請
- 邀請中的老師
- 待處理 OB
- 取消／退出申請
- API 核對異常
- 已完成紀錄

「待處理 OB」顯示原老師、代課老師、原課程、預計實際課程、難度、備註及是否需要新增課程。管理者人工修改 OB 後，按「重新同步並核對」。

核對以 OB calendar ID 為主，比對代課老師、實際課程與可取得的難度資訊。完全一致即寫入核對時間並標記完成；找不到課程或內容不一致才保留在異常清單。若新增 OB 課程導致 ID 改變，管理者可指定新舊課程對應後重新核對。

## Google Sheets 資料契約

既有欄位與索引保持不動；只改工作表名稱並在右側追加欄位。

### `CourseList`

固定欄位：

- A 日期（`r[0]`）
- B 時間（`r[1]`）
- C 課程（`r[2]`）
- D 指導者（`r[3]`）

自 E 欄起追加 OB calendar ID、class ID、老師 ID、是否代課、最後同步時間等 API 欄位。

### `請假代課紀錄`

原 `工作表1` 重新命名為 `請假代課紀錄`，不搬動既有資料：

- A 登記時間
- B 原老師（`r[1]`）
- C 日期（`r[2]`）
- D 時段（`r[3]`）
- E 課程（`r[4]`）
- F 狀態（`r[5]`）
- G 代課老師（`r[6]`）
- H 備註（`r[7]`）
- I 入系統
- J 代課編號

自 K 欄起追加 OB calendar ID、實際課程 ID／名稱、預計難度、處理類型、OB 核對狀態、核對時間、差異原因及異動狀態。所有程式統一改用新工作表名稱，不保留兩張平行主表。

### 新增工作表

- `代課邀請`：邀請 ID、老師、開放時間、查看時間、狀態、關閉時間。
- `操作紀錄`：時間、操作者、操作類型、目標編號、前後狀態與原因。
- `系統設定`：同步資訊、全站暫停開關及非機密設定。

老師登入資料可追加於受保護的老師資料表，或建立受保護的 `登入帳號` 工作表；不得透過一般老師 API 回傳完整名單、密碼雜湊或管理權限。

## 使用者需準備的資料

### 老師資料

- 指導者顯示名稱，並確認與 OB 名稱的對應。
- 身分證末碼，用於建立登入雜湊。
- 可教授的道具／課程類別，可填多個。
- 是否在職。
- 是否具有管理權限。
- 既有序位與梯次可保留為管理端資料，不向老師顯示；手動邀請不要求先補齊。

### 系統資料

- 旋轉後的新 Omcean API token，設定於 `OMCEAN_API_TOKEN`。
- 至少一組管理員登入資料。
- 正式的課程／道具類別清單與名稱對照。

既有請假與代課資料不需重新輸入。部署程序負責重新命名工作表、追加標題與回填可安全推導的 ID；無法可靠推導的舊資料標示為待人工核對，不得猜測。

## 錯誤處理與安全規則

- 所有寫入使用 POST、統一 JSON 回應與輸入驗證。
- 領取、取消、退出、邀請和同步使用適當的 `LockService` 鎖定。
- 前端只有收到後端成功回應與正確筆數後才顯示成功。
- 大量請假採分批提交；部分失敗時列出失敗項目，不重複建立已成功資料。
- API 同步失敗時保留舊 `CourseList`，並在管理端顯示錯誤。
- 缺少工作表、欄位、session、權限或必要備註時停止寫入並回傳明確訊息。
- API token、登入末碼與密碼雜湊不得出現在前端、GitHub、記錄訊息或一般 API 回應。

## 驗收標準

- 老師登入後只能看到自己的資料；管理頁需要管理權限。
- 日期先選、全選、清除與大量請假均可正確完成。
- 大量請假不會因網址長度而假成功，成功筆數與試算表一致。
- 未受邀老師看不到待領代課；受邀老師看到全部待領項目但看不到排序與他人身份。
- 老師不能領取自己請假的課。
- 多人同時領取時只有一人成功，其他畫面立即更新。
- 跨道具領取強制填寫改課內容與備註；同道具仍可填難度與備註。
- 自行取消、申請取消與申請退出符合狀態規則並留下紀錄。
- 手動 API 同步不覆蓋請假歷史；失敗不清空現有課表。
- OB 核對只把不一致項目留在異常清單。
- 原 A 至 J 欄資料與既有索引不被移動。
- 桌機與手機均可完成登入、請假、領取、查詢與異動申請，且無水平溢出或內容重疊。

## 非本階段範圍

- 自動 LINE 發送。
- 自動依梯次或期限開放下一位老師。
- 透過 API 寫回 OB。
- 薪資計算、薪資檢查與薪資明細頁。
