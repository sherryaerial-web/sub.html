# 特別課課名核對正規化設計

## 問題

特別課群組已能以一堂實際 OB 課程對應多個原代課時段，但核對仍使用一般課程的完整字串比對。老師填寫的「後彎主題十字墊瑜伽&頌缽充電」與 OB 的「B－後彎主題十字墊瑜伽＆頌缽充電特別課 (150min)」因此被誤判為不同課程。

## 決策

只在特別課群組核對時使用專用課名正規化：

- 移除開頭教室前綴，例如 `B－`。
- 統一半形 `&`、全形 `＆` 與 `﹠`。
- 移除尾端 `特別課`。
- 移除尾端半形或全形括號的分鐘數，例如 `(150min)`、`（150分鐘）`。
- 忽略空白與英文大小寫。
- 其餘主要課名必須完全一致；代課老師仍必須完全一致。
- 一般代課、既有 Class ID 核對、群組唯一 OB 課程規則均維持不變。

## 資料安全

不新增、搬移或重寫任何工作表欄位，不執行 OB 同步或核對。程式部署後由管理員手動按「重新核對 OB」，才會依既有交易與稽核流程更新核對狀態。

## 驗證

新增真實課名格式的後端回歸測試，確認三個群組時段一起完成；另保留主要課名不同時仍判異常的保護測試，最後執行完整測試與 GAS 語法檢查。
