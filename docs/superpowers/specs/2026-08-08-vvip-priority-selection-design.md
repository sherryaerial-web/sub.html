# VVIP 優先選課意願登記設計規格

日期：2026-08-08  
專案：Sherry Aerial Studio 教室內部管理網站  
前端：新增 `vvip.html`，管理功能整合至 `index.html`  
後端：Google Apps Script + Google Sheets + 現有 `CourseList`

## 目標與範圍

每月提供 VVIP 一個免登入的優先選課頁面。會員輸入 Email，查看 OB 下個月全部有效課程，分次累積登記最多四堂選課意願。此功能只收集意願，不代表正式保留 OB 名額；會員選錯時聯絡管理員，由管理員後台取消。

本階段不做 VVIP 名單預先驗證、不寄送 Email、不自動寫回 OB、不提供會員自行取消。

## 會員流程

1. 開啟獨立公開頁面 `vvip.html`。
2. 輸入 Email 後查詢本期已累積堂數與課程。
3. 顯示 `CourseList` 中下個月全部有效課程，依日期分組，顯示日期、時間、課程與老師。
4. 會員可搜尋課程或老師，勾選尚未選過的課程。
5. 送出前顯示本次選擇與累積總數；同一 Email 同一月份最多四堂。
6. 多次送出採累積制，不覆蓋舊選擇；同一 OB Calendar ID 不重複計算。
7. 若本次新增後超過四堂，整批拒絕，不部分寫入。
8. 成功後顯示完整累積清單，並提醒意願登記不等於正式保留名額。

Email 需去除前後空白、轉為小寫並驗證格式。第一版不驗證是否為既有 VVIP；所有新登記標記為「待人工確認」。

## 開放與課程來源

- 管理員在後台手動開放或關閉本期選課，不設自動期限。
- 課程直接使用現有手動 OB 同步後的 `CourseList`，只顯示下個月有效課程。
- 管理員開放前，後端必須確認 `CourseList` 具有下個月課程及 OB Calendar ID；否則拒絕開放。
- 選課關閉時，公開頁只顯示本期已截止，不接受查詢或送出。

## 管理後台

現有管理頁新增「VVIP 選課」工作區：

- 手動開放／關閉本期選課。
- 顯示本期月份、登記人數、有效選課總堂數。
- 依 Email 搜尋，查看每位會員的累積課程。
- 將 Email 標記為「已確認」或維持「待人工確認」。
- 取消單堂並填寫原因；取消紀錄保留，但不再計入四堂上限。
- 依課程查看登記會員。
- 匯出本期有效選課清單為 CSV。

VVIP Email 只在公開 VVIP API 與管理員 API 使用，不提供老師端或請假代課 API。

## Google Sheets 契約

新增 `VVIP選課紀錄`：

- A 登記時間
- B Email
- C 月份（`yyyy-MM`）
- D OB Calendar ID
- E 日期
- F 時間
- G 課程
- H 老師
- I 狀態（待人工確認／已確認／已取消）
- J 確認時間
- K 取消時間
- L 取消原因
- M 操作者

新增 `VVIP選課設定`：

- A 設定鍵
- B 設定值
- C 更新時間
- D 操作者

設定鍵至少包含 `activeMonth`、`isOpen`、`openedAt`、`closedAt`。所有新增欄位採獨立工作表，不更動既有 `CourseList`、`請假代課紀錄` 或登入帳號索引。

## 後端規則

- 公開 GET 僅提供系統連線文字；VVIP 查詢與送出均使用 form-encoded POST，避免 Email 出現在 URL。
- 查詢只回傳該 Email 本期選擇與公開課程欄位，不回傳其他 Email。
- 送出使用 `LockService`，在鎖內重新計算有效堂數、去除重複並驗證四堂上限。
- 寫入採整批全有或全無；寫入失敗不得留下部分課程。
- 管理操作使用現有管理員 Session，取消與確認保留稽核紀錄。
- CSV 匯出只允許管理員，並對公式開頭字元進行 CSV injection 防護。

## 畫面設計

`vvip.html` 延續清透藍綠、白色與中性色的教室品牌，但比管理後台更簡單。頁首清楚顯示「VVIP 優先選課意願登記」、本期月份及「不代表正式保留名額」。課程依日期單欄分組，固定顯示「已選 N／4 堂」，手機不使用遮擋內容的浮動導覽。

## 錯誤處理

- 無下月課程、尚未開放或已關閉：不接受登記。
- Email 格式錯誤：不查詢、不送出。
- 重複課程：忽略重複項目並回傳目前累積清單。
- 超過四堂：整批拒絕並顯示目前已選與本次超額項目。
- 課程在頁面載入後被移除：送出時拒絕該整批並要求重新整理。
- 網路或後端錯誤：保留畫面勾選並提供重試。

## 驗收標準

- 同一 Email 可分次累積，最多四個不同 OB Calendar ID。
- 第五堂或造成總數超過四堂的批次不會部分寫入。
- 管理員取消後可重新補選，取消歷史仍保留。
- 未開放、無下月課程或缺少 Calendar ID 時不能送出。
- 管理員可搜尋、確認、取消、依課程檢視與匯出。
- VVIP Email 不出現在 URL、老師 API 或前端程式碼常數。
- 桌機與手機無水平溢出、遮擋或文字裁切。

## 測試策略

開發途中只執行 VVIP 相關後端、前端契約與必要畫面測試。不重跑代課系統完整測試，也不派多輪完整審查；只有整個網站正式上線前，才執行一次完整測試與總驗證。
