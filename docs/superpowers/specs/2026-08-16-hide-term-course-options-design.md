# 領代課選單排除期班設計

## 問題與範圍

正式 `CourseList` 的「空環 Lv.3 技巧訓練期班」在相同星期與時間出現兩次，符合現行「重複至少兩次即為常態課」的 catalog 規則。現行規則只排除「特別課」與「場地租借」，因此期班進入老師調整課程的課程類型選單。

本修正只讓所有名稱含「期班」的課程從調整課程選項消失，不刪除 `CourseList` 資料、不隱藏待領代課卡片，也不影響老師直接沿用原課程。

## 設計

- 後端 `buildRecurringClaimCourseOptions_()` 在建立可選 catalog 時排除名稱含「期班」的課程。後端查找實際課程也使用同一 catalog，因此偽造或舊前端送出的期班選項會找不到，不會被接受。
- 前端 `getTeachableClaimClasses()` 同步排除名稱、課程類型名稱或 key 含「期班」的項目，避免 GAS 快取或舊回應短暫讓期班出現在選單。
- 不修改任何 Sheet 欄位、列或課程名稱；不需要資料搬移或同步 CourseList。

## 測試與發布

- 後端回歸測試：同星期同時段重複兩次的期班仍不進入 catalog，一般常態課與綢吊 90 分鐘課保持可選。
- 前端回歸測試：混合一般課與期班的 API 回應只顯示一般課，期班不能被解析成送出選項。
- 完整測試通過後發布新的 GAS Web App version，並推送 GitHub Pages 前端防呆。
