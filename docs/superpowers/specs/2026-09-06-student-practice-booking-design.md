# 學生自主練習登記設計

日期：2026-09-06  
狀態：冠蓉與 Tako 已確認

## 目標

建立一個不需登入教室管理 APP 的學生頁面，只顯示學生可登記的 A／B／C／D 教室空檔與「已有學生練習，可一起使用」的時段。學生送出的資料直接進入管理後台，Tako 不需重複輸入。

## 優先順序與時間

1. 正式課程。
2. 場地租借。
3. 老師自主練習。
4. 學生自主練習。

- 前三類時段對學生一律不開放，不顯示人名或內部課程資料。
- 學生自主練習保留前後各 15 分鐘，可選 60／90／120 分鐘；頁面只提供實際放得下的時長。
- 最晚必須在開始前 2 小時送出；取消或更換時間也是開始前 2 小時，並由官方 LINE 聯繫 Tako 處理。
- 所有後端日期與時間固定使用 `Asia/Taipei`。

## 學生頁面

- 空檔顯示「空教室，可選擇練習時長」，預設 60 分鐘，空檔足夠才顯示 90／120 分鐘。
- 已有學生場次顯示「已有學生自主練習，可登記一起使用」，不顯示已登記者姓名，加入者沿用該組原本時間。
- 同一教室、同一時段只有一組，不設固定人數上限；每位學生仍有獨立登記、資格狀態與扣點。
- 第一次需填 OB 登記姓名與辨識資料；成功後以不可猜測的學生 token 綁定這台裝置，以後盡量帶入。

## 資格狀態

- 只記錄整體「可自主練習／待確認」，不分空環、舞綢、鞦韆或綢吊。
- 已有資格：送出後直接成立。
- 沒有資格紀錄：保存原送出資料並顯示「已收到申請，目前待老師確認，尚未成立，請勿重複送出」。
- 資格依館別分開記錄：晴光適用 A／B 教室，劍潭適用 C／D 教室；Tako 在後台確認申請館別的資格後，原申請直接轉成立，不需再輸入姓名、日期、教室與時間，另一館仍須另外確認。

## 取消、換時間與高優先異動

- 取消只移除該學生；最後一人取消後場次才釋出。
- 換時間先確保新時段成立，再釋放舊時段；新時段失敗時舊登記保留。同組其他學生不受影響。
- 新正式課程或場租插入時，改標記「時段異動待處理」並通知管理員，不靜默刪除。Tako 先詢問學生是否換時段，無法替代才取消與人工退點。

## OB 與 LINE 邊界

- 現有 OB API 尚不負責建立學生預約或扣點；Tako 繼續在 OB 當月「自主練習扣點」項目人工補登。
- 不需回系統另外標記「已扣點」。
- 官方 LINE 關鍵字「自主練習」將回覆公開網址、資格提醒、2 小時限制、共用說明與取消／換時間管道。LINE 自動回覆與學生綁定可在核心登記上線後單獨串接。

## 資料與安全

- 新增獨立工作表：`學生自主練習資格`、`學生自主練習場次`、`學生自主練習參與者`、`學生自主練習操作紀錄`；資格表在既有身分欄位後追加晴光與劍潭各自的狀態、確認時間及確認者欄位。
- 不修改、清空、搬移老師自主練習五張表，也不寫入 CourseList。
- 所有更新使用 UUID 找明確列，並在 LockService 內重新檢查當日 OB、場租、老師練習與學生場次。
- 公開讀取只回傳日期、教室、起訖時間、可用時長與是否為共用場次，不暴露學生、老師、OB ID 或課名。

## 第一個可測版本

1. 公開學生頁面與可用時段 API。
2. 第一次學生身分建立與不可猜測 token。
3. 空檔建立／同組加入，及資格待確認。
4. Tako 後台查看、確認資格、取消與換時間。
5. LINE 自動回覆、綁定與通知作為後續串接，不阻擋核心流程驗收。
