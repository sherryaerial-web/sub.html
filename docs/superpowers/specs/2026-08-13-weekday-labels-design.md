# 教師列表日期星期顯示設計

## 目標

所有教師端請假與代課日期統一顯示為 `YYYY/MM/DD（週別）`，例如 `2026/09/24（四）`，讓老師不必自行對照星期。

## 範圍

- 請假登記的日期選擇
- 請假登記的課程列表與送出確認列表
- 我的請假紀錄
- 領取代課的日期群組標題
- 我的代課紀錄

管理後台與資料匯出不在本次範圍內。

## 實作設計

在前端建立一個共用日期格式函式，接受現有 `YYYY/MM/DD` 或 `YYYY-MM-DD` 字串，依台灣日期計算星期，輸出 `YYYY/MM/DD（四）`。所有上述畫面只在顯示時呼叫此函式；排序、篩選、API payload 與 Sheet 儲存值仍使用原始日期。

若輸入不是有效日期，函式直接回傳原字串，避免單筆異常資料造成整個列表無法顯示。

## 資料與安全

- 不修改 Apps Script、Sheet 欄位或正式資料。
- 不改變 OB Calendar ID、代課編號或日期原值。
- 僅發布 `index.html` 的顯示邏輯。

## 測試與驗收

- 先新增失敗測試，確認 `2026/09/24` 會顯示為 `2026/09/24（四）`。
- 驗證斜線與連字號日期，以及無效日期的安全回退。
- 驗證請假列表與領取代課列表的實際 HTML 都包含星期。
- 跑完整前端契約測試，再核對 GitHub Pages 正式頁包含新版函式與呼叫點。
