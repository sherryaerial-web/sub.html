# 管理者結果匯出 Excel 設計

## 目標

在管理者工作台提供「匯出 Excel」按鈕，將目前登入管理者有權限查看的結果整理為一個真正的 `.xlsx` 活頁簿。每類資料放在不同工作表，方便管理者篩選、保存與交接。

## 匯出範圍

- 課程管理權限：`代課結果`、`待領取`、`邀請中`、`待處理OB`、`取消退出`、`核對異常`。
- 薪資管理權限：`薪資總表`、`薪資明細`、`薪資異議`。
- VVIP 管理權限：`VVIP選課`。
- `代課結果` 由已有人領取、OB 處理中、核對異常與已完成資料合併後依代課 ID 去重，保留狀態欄位供管理者判讀。
- 不匯出 PIN、雜湊、Salt、Session Token 或其他登入敏感資訊。

## 行為與安全規則

- 點擊時重新向既有唯讀管理 API 取得最新資料，不依賴畫面上可能過期的快取。
- 任何有權限的資料來源載入失敗時，中止匯出並顯示錯誤，避免產生看似完整但缺頁的檔案。
- 不新增或修改 Google Sheet、Drive 檔案與 Apps Script 資料；所有活頁簿組裝都在瀏覽器完成。
- 文字若以 `= + - @` 開頭，匯出前加上文字保護，避免 Excel 公式注入。
- 空資料仍保留該工作表與欄位標題，讓管理者知道資料類別已正確匯出。
- 檔名格式為 `Sherry教室管理_YYYY-MM-DD.xlsx`。

## 技術方式

- 將 SheetJS CE 0.20.3 的瀏覽器版檔案固定存放於專案 `vendor/`，避免正式頁面執行時依賴第三方 CDN。
- 前端新增可獨立測試的資料整理函式，負責權限分頁、欄位轉換、去重、儲存格保護與欄寬設定。
- 匯出按鈕沿用管理頁現有按鈕樣式，忙碌時停用並顯示進度，手機版不可造成橫向破框。

## 驗證

- 前端契約測試覆蓋按鈕、權限分頁、結果去重、敏感欄位排除、公式注入保護與錯誤中止。
- 使用固定版 SheetJS 實際產出 `.xlsx` 後重新讀取，確認工作表名稱與代表資料正確。
- 執行手機管理頁視覺檢查，確認新增按鈕不破框。
