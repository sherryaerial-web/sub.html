# 莫蘭迪奶茶陶粉視覺調整規格

日期：2026-08-09

## 目標

將教室內部管理網站與 VVIP 選課頁面，從目前的深綠、襯線標題風格，調整為使用者選定的「C｜奶茶陶粉」莫蘭迪色系。改善中英文字體不協調與整體色彩偏綠的問題，同時保留既有功能、權限與資料流程。

## 視覺方向

- 主色：暖灰棕 `#786c64`，用於頂部導覽與主要品牌區。
- 互動重點：陶土粉 `#ad8175`，用於目前狀態、圖示、重點線條與選取狀態。
- 頁面底色：奶茶暖灰 `#f3f0eb`。
- 內容表面：暖白 `#fffdf9`。
- 側邊區域：淺奶茶灰 `#ebe5dd`。
- 主要文字：炭棕 `#403936`。
- 次要文字：暖灰 `#786f69`。
- 邊框：低對比灰褐 `#d8d0c7`。
- 柔和提示底色：淡陶粉 `#eee0dc`。
- 錯誤、成功與警示狀態仍保留可辨識的語意差異，不全部改成同一個粉色。

## 字體

- 中文：`Noto Sans TC`，後備為 `PingFang TC` 與系統無襯線字體。
- 英文與數字：`DM Sans`，後備為系統無襯線字體。
- 標題、品牌、金額與內文統一使用無襯線系統，不再使用 Georgia 或其他襯線字體。
- 標題以字重與尺寸建立層級，字距維持 `0`。

## 套用範圍

1. `index.html`
   - 登入畫面、頂部導覽、側邊導覽、首頁入口卡片。
   - 請假、代課、我的薪資與管理員工作區。
   - 按鈕、表單、狀態標籤、訊息提示與空狀態。
2. `vvip.html`
   - 品牌區、會員選擇、月份與課程清單。
   - 選課計數、送出按鈕、成功與錯誤提示。

## 行為與資料限制

- 不修改 JavaScript 流程、GAS action、Google Sheets 欄位、權限或 API 契約。
- 不新增照片、插圖、品牌圖示或大面積裝飾。
- 不改寫既有介面文字，僅在必要時調整純視覺用的字體與樣式。
- 桌機與手機沿用現有資訊架構，避免導覽、按鈕或長文字重疊。

## 驗證

- 開發時只執行與樣式修改直接相關的 HTML／JavaScript 語法檢查與少量桌機、手機畫面檢查。
- 確認無水平溢出、文字截斷、對比不足、互動狀態不清楚或功能流程改變。
- 正式上線前再執行一次完整測試與完整桌機／手機視覺驗證。
